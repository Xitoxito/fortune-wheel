# fortune-wheel
# 🎡 Колесо фортуны

Интерактивное колесо фортуны с системой редкостей и анимациями.

Вставляешь список вариантов — колесо само раздаёт им редкости (обычный, редкий, супер удача). Шанс у всех одинаковый, но каждый уровень имеет свой цвет и уникальную анимацию при выпадении.

## Возможности

- Один список на вход — редкости раздаются автоматически
- Три уровня редкости с уникальными цветами и эффектами
- Ручная смена редкости нажатием на чип варианта
- Конфетти, свечение и тряска экрана при супер удаче
- Звуковые эффекты (Web Audio API, без внешних файлов)
- Криптографический рандом (`crypto.getRandomValues`)
- Опция «убирать выпавший вариант»
- История последних 20 результатов
- Сохранение в localStorage
- Адаптив под мобильные
- Нулевые зависимости, один HTML-файл
